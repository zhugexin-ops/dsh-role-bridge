# dsh-role-bridge（叫她 / 养鱼）

给 DSH 装一个**外骨骼**：让 AI 角色不再困在单个对话里，而是住在你自己的硬盘上。

- `plugin/` —— DSH 插件（可上架市场的那一半：菜单、外骨骼接管、会话入口）
- `engine/` —— 角色引擎（Python，零第三方依赖：权重 / 四元与信任 / 两种检索 / 政治层）
- `site/`  —— 插件市场的静态索引源（`index.json`）
- `上架.md` —— 从零开始的图文步骤（给非程序员）

## 它不是聊天机器人

角色是目录：`角色/<名字>/memory.sqlite` + 她的宪法 + 她的账。插件只是入口，壳可以换，人和她的记忆不换。

## 快速开始

见 `上架.md`（安装）与 `plugin/README.md`（插件细节）。
